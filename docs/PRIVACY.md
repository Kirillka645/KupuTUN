# Политика конфиденциальности KupuTUN

_Действует с версии 1.0.0._

KupuTUN — VPN/прокси-клиент. Приложение **не собирает, не продаёт и не передаёт** персональные данные
разработчику или третьим лицам. У приложения нет своих серверов, аналитики и рекламы.

**Что хранится только на устройстве**
- Ссылки подписок, серверы и настройки — в зашифрованном хранилище (Android Keystore, AES-256-GCM).
- Результаты пинга и тестов скорости — в локальной базе данных.
- Последний конфиг для плитки/автозапуска — зашифрован ключом Android Keystore.

**Сетевые запросы**
- Загрузка подписок по ссылкам, которые добавил пользователь (и встроенные публичные списки).
  Провайдеру подписки передаются стандартные заголовки клиента (User-Agent, версия ОС, модель
  устройства, случайный идентификатор устройства `x-hwid`) — как в Happ.
- Проверка серверов (ping/скорость) и обновление geo-файлов.
- Весь трафик устройства при включённом VPN направляется на выбранный пользователем сервер.
  KupuTUN не просматривает и не записывает этот трафик.

**Разрешения**
- VPN (VpnService) — создание туннеля; уведомления — статус подключения и кнопка «Отключить»;
  камера — только сканирование QR-кода; список приложений — раздельное туннелирование;
  автозапуск — переподключение после перезагрузки (если включено).

**Удаление данных** — удалите приложение или очистите его данные в настройках Android.
